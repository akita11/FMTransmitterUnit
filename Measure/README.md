# 電磁界強度の測定方法と測定結果

## 関連する法令と基準

- FMラジオ向けの小型トランスミッタは、電界強度が基準以下なら「著しく微弱な電波を発する無線局」（微弱無線局）に当たり、免許は不要。
- 販売のための法定認証は不要（ELPマーク（微弱無線適合）やTELEC認証は任意）だが、責任は製造者・販売者にある。
- 測定方法: 告示127号の3m法。
  - 受信アンテナは基本的にはダイポール（バイログアンテナでも可能）
  - 電界強度の許容値は以下の通り。
    - 322MHz以下: 500µV/m (約54dBµV/m)
    - 322MHz - 10GHz: 35µV/m (約30.9dBµV/m)


## 測定方法・機材

- 測定日：2026/11/20
- 測定場所：石川県工業試験場（石川県金沢市鞍月2-1）
- 測定機材
 - エミッション測定装置
   - スペクトラム・アナライザ: Rohde&Schwarz ESU26
   - バイログアンテナ: ㈱東陽テクニカ製
   - 解析ソフトウエア：東陽テクニカ・EP5/ME
 - 電波無響室（トーキン、主な仕様は以下の通り）
   - 周波数範囲：30MHz〜18GHz
   - シールド性能：100dB以上
   - 面積：40m2（W8m x D5m x H6.3m）
   - ターンテーブル：直径2m
- 測定環境：MeasurementSetup.png の通り。以下の合計8条件で測定し、最大値を求めた。
  - バイコニアンテナの高さ: 1m, 2m, 3m, 4m
  - バイコニアンテナの偏波方向: H（水平）, V（垂直）

## 測定結果

Measurememt_result.pdfの通り。
- p.1: 測定対象デバイスの送出周波数=87.5MHz
